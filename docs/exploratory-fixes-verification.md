The automated cases are in [exploratory-regressions.spec.ts](../tests/e2e/exploratory-regressions.spec.ts). They run in Chromium, Firefox, and WebKit. API fixtures make the regressions repeatable; Stockfish, WebAssembly workers, IndexedDB, page layout, and offline simulation are real.

Additional UX corrections:

- Existing local datasets recover automatically after reload, with the last tab, selected game, move, and Review/Analysis mode. A deleted dataset is not automatically imported again. The form also pre-fills the saved query.
- The opening table visibly identifies position-wide counts across move orders, separately from matching games in the selected line.
- Insights identifies local versus Chess.com accuracy contributions and reviewed-game coverage. Unevaluated tactical totals display Unknown.
- Selecting the Black Insights filter opens the Black openings tab.
- Profile update text identifies account-wide lifetime rating peaks and the loaded-game scope of performance filters.
- Missing-account and reversed-date messages use actionable wording. Editing fields or choosing a date preset clears old validation messages and stale upstream feedback.
- Deletion wording explains that view preferences and recent search history are retained. Saved review records are deleted with their user; Clear all removes all database records.

## Validation

- `npm run test:coverage`: **762 tests passed in 90 files**. Global coverage: 88.23% lines/statements, 83.90% branches, 82.76% functions; configured coverage gates passed.
- `npm run build`: passed compilation, TypeScript, and static generation.
- `npm run typecheck`, `npm run lint`, `npm run format:check`: passed.
- Production Playwright regression suite: **142 passed** (`npx playwright test --workers=2`), covering Chromium, Firefox, WebKit, Pixel 7, and iPad layouts, with ordinary visual comparisons enabled.
- After the live check exposed HTTP-cache reuse during an offline refresh, profile requests were changed to bypass HTTP caching. The affected profile/Insights browser cases were rerun on the final build: **6 passed** across Chromium, Firefox, and WebKit. The API contract test also verifies the network cache policy.
- Development analytics repeat: **3 passed**, one each in Chromium, Firefox, and WebKit.
- Additional live Hikaru journey: passed against the final production build. Imported **500** Last-30-days games and navigated the exact reported `Nf3 d5 d4 Nf6 e3` transposition; imported **12** games for 2026-11-09 UTC; completed an actual **95/95-ply Quick review**; reloaded and retained **48 evaluated user moves**, the Insights tab, and the completed review. Real populated Insights measured exactly **390px** and **320px** at those viewport widths; all five targeted axe contrast/landmark rules passed. A real offline profile refresh displayed an error and retained the previous successful-update timestamp. No uncaught browser errors were recorded.

Logs and captures are in [fix-verification-evidence](fix-verification-evidence/). Original audit captures are preserved unchanged. Generated browser evidence is excluded from source formatting checks.

Visual baselines were reviewed and refreshed for the visible opening-scope text and a consistent scroll position. The initial-screen baselines stayed unchanged. The ordinary suite, without snapshot updates, verifies the refreshed baselines.

The original audit's untested scenarios (such as exhaustive engine-score correctness, storage quota failures, all historical archives, and physical mobile hardware) are not claimed as certified by these checks.
